# AutoForge ERP — Módulo Financeiro

## 1. Objetivo

O módulo financeiro será responsável pela gestão das operações financeiras geradas pelo AutoForge.

O módulo deverá controlar:

- contas a pagar;
- contas a receber;
- obrigações financeiras;
- receitas;
- despesas;
- parcelas;
- vencimentos;
- baixas;
- categorias financeiras;
- centros de custo;
- contas financeiras;
- caixa;
- fluxo de caixa;
- inadimplência;
- conciliação;
- condições de pagamento;
- histórico financeiro;
- previsões financeiras;
- auditoria.

O módulo deverá integrar-se principalmente com:

- clientes;
- fornecedores;
- compras;
- ordens de serviço;
- orçamentos;
- estoque;
- fiscal;
- pagamentos;
- CRM;
- dashboard;
- auditoria.

---

# 2. Conceito

O financeiro será responsável por registrar e controlar os compromissos financeiros gerados pelas operações do AutoForge.

O módulo deverá separar:

```text
Contas a Pagar
      ↓
Obrigações
      ↓
Parcelas
      ↓
Pagamentos
```

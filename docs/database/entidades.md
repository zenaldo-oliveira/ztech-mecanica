# AutoForge ERP — Entidades do Sistema

## 1. Objetivo

Este documento define as principais entidades de negócio e suporte do AutoForge ERP.

O objetivo é estabelecer uma referência única para:

- banco de dados;
- backend;
- APIs;
- regras de negócio;
- integrações;
- permissões;
- auditoria;
- testes.

As entidades aqui descritas representam o modelo conceitual do sistema.

A definição física definitiva das tabelas, tipos, índices, constraints e detalhes específicos do ORM deverá ser documentada em:

```text
docs/database/modelo-dados.md
```
